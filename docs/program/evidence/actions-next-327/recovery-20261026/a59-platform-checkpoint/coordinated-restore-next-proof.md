## Actual implementation gap versus proof gap

Inspection does not establish a product defect or a missing restore primitive for all components. If the planned harness discovers that an independently copied RCC home cannot be loaded by the pinned consumer, that is a concrete implementation gap to diagnose; current receipts only prove that the old cache stayed available, so do not presume cache portability.

Do not claim full restore from copying a datadir, from a successful `pg_dump`/object copy, or from the a57 legacy receipt. Those are distinct partial proofs.
