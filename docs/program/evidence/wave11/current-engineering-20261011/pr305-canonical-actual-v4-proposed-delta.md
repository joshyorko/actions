A post-command admission assertion can fail after a zero exit status without carrying stdout or stderr attributes. Retain the returned CompletedProcess streams before admission, and do not replace them with empty exception fallback streams. If the original launch or named-case report bytes are missing, hold that acceptance even when persisted tool Runs and cleanup fields are independently measurable. Command exit status, testcase/report admission, Runtime cleanup, and outer subreaper cleanup remain separate evidence.
