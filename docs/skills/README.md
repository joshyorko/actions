# Canonical Agent Guides

Repository-local operational knowledge lives here. Read root `AGENTS.md` first, then the guide matching the affected subsystem.

| Guide | Use for |
|---|---|
| [Repository operations](repository-operations.md) | Package boundaries, environments, testing, commits, releases, and evidence rules |
| [Work Items](work-items.md) | `actions-work-items`, adapters, queues, attachments, Action Server integration, and backend support |

Update an existing guide before creating another. Add every new canonical guide to this index in the same commit.

Guidance must be supported by code, tests, command output, an observed failure, or an immutable upstream source. Remove stale or contradictory claims when evidence changes. Do not store per-run diaries here.
